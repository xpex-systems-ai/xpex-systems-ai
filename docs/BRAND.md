## Visual direction

Primary:
- near-black / black;
- warm metallic gold;
- white.

Functional states:
- green = verified / healthy;
- amber = review / pending;
- red = blocked / security issue;
- graphite = neutral infrastructure.

## Brand behavior

The visual language can be premium and cinematic.

The claims must remain technical and evidence-backed.

Avoid:
- invented metrics;
- fake certification badges;
- unsupported partnership logos presented as endorsement;
- fake customer logos;
- fake revenue;
- vague "world's best" claims.

## Logo / asset policy

Before public use of third-party logos, verify:
- trademark usage terms;
- whether logo display implies partnership;
- whether attribution or permission is required.

Prefer text such as "Technology used" when the relationship is only technical usage.
