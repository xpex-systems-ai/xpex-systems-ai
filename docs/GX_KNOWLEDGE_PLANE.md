# GX Ecosystem Knowledge Plane — V1

## What “neural transfer” means in XPeX

XPeX does **not** copy the founder's private ChatGPT memory, credentials, connected accounts or hidden conversation history into a public website.

Instead, it performs a governed knowledge transfer:

```text
AUDITED SYSTEM
  → canonical identity
  → source
  → runtime
  → architecture
  → security boundaries
  → evidence
  → media classification
  → JSON manifest
  → GX retrieval context
  → public system intelligence page
```

That is the enterprise version of “putting GX inside the ecosystem”.

## System Intelligence Pages

Every evidence-backed flagship now has a dedicated public intelligence page:

- XPeX Systems Command
- GXEON Wallet Command Center
- GXEON Audit OS
- XPeX Plugin Factory
- XPeX Studio AI
- XPeX API Fabric / Agent Marketplace
- XPeX Academy

Each page is designed like a streaming-product detail surface, but its purpose is technical verification:

1. cinematic identity / positioning;
2. current status;
3. provider + environment + runtime state;
4. problem and product description;
5. architecture flow;
6. stack;
7. runtime/live preview when safe;
8. governed media classifications;
9. security boundaries;
10. open gates / limitations;
11. direct evidence links;
12. public JSON manifest;
13. connected-system graph;
14. one-click handoff to GX.

## Knowledge Graph

The machine-readable graph includes the **20 material asset lineages** already discovered in the corporate audit.

Seven receive full public detail pages today. The remaining lineages stay discoverable as graph nodes until they pass stronger identity/runtime/evidence gates.

This is intentional: **knowledge coverage can be broader than public product promotion.**

## GX knowledge modes

### Public GX
Can answer from:
- corporate evidence registry;
- 7 detailed System Intelligence manifests;
- 20-lineage ecosystem graph;
- public source/runtime/security references.

### Private/operator GX
May use additional connected tools and operator context according to permissions.

These two scopes are intentionally separated.

## Truth boundary

“GX knows the ecosystem” means GX receives a structured, auditable knowledge representation of the ecosystem.

It does **not** mean the public agent gets unrestricted access to secrets, private memory, wallets, customer data, admin controls or infrastructure write permissions.
