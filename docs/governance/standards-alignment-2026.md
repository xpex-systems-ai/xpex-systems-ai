# XAGF Standards Alignment — 2026 Snapshot

**Status:** Alignment reference, not certification.

XAGF is designed to remain compatible with evolving external guidance.

## NIST AI Risk Management Framework

NIST AI RMF 1.0 remains an important voluntary risk-management baseline while NIST is revising it. NIST AI 600-1 remains the Generative AI Profile.

XAGF maps conceptually to:
- GOVERN;
- MAP;
- MEASURE;
- MANAGE.

Official references:
- https://www.nist.gov/itl/ai-risk-management-framework
- https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence

## NIST SSDF / AI software development

XAGF Secure AI SDLC is designed to align with NIST SSDF practices and AI-specific secure development guidance, including SP 800-218A concepts.

Reference:
- https://csrc.nist.gov/projects/ssdf

## OWASP GenAI / Agentic Security

XAGF security tests should track current OWASP guidance for:
- LLM / GenAI application risks;
- Agentic Application risks;
- agent control / skill risks;
- MCP/tool boundaries.

2026 references:
- https://genai.owasp.org/resource/owasp-genai-llm-top-10-2026/
- https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/

## SLSA

XPeX uses SLSA concepts for provenance and supply-chain integrity. The current SLSA specification should be treated as an external reference, not as a self-awarded level.

Reference:
- https://slsa.dev/spec/v1.2/

## ISO/IEC 42001

XAGF includes AI-management-system concepts such as policy, roles, risk, monitoring, review and improvement.

Formal ISO/IEC 42001 certification requires an external certification process.

## Continuous review

This alignment file is versioned because external standards evolve.

A changed standard does not automatically mean XPeX controls are compliant; mappings must be re-reviewed and evidence updated.
