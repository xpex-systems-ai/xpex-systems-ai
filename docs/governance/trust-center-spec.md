# XPeX Public Trust Center — Specification

## Purpose

The future Trust Center gives customers, partners and investors a transparent view of XPeX governance without exposing internal security-sensitive evidence.

## Public sections

### Governance
- XAGF overview;
- governance principles;
- risk model;
- human oversight;
- agent autonomy levels.

### Security
- secure SDLC overview;
- secrets policy;
- supply-chain policy;
- vulnerability reporting channel;
- incident-response overview;
- business continuity overview.

### AI Transparency
- model/provider governance;
- AI system cards for approved public systems;
- agent capability summaries;
- public limitations;
- last verification date.

### Privacy
- data classification;
- minimization;
- retention principles;
- customer-data handling summary.

### Evidence
For approved systems:
- verified source status;
- verified runtime status;
- assurance level;
- relevant control coverage;
- verification date.

### Compliance
Only factual status:
- frameworks aligned to;
- audits completed;
- certifications actually obtained.

Never display a certification badge that has not been formally earned.

## Disclosure model

Public trust data is a sanitized projection of the internal evidence graph.

`Internal Evidence → Security Review → Disclosure Approval → Public Trust Record`

The public Trust Center never reads secrets or unrestricted internal findings directly.
