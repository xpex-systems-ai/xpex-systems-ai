# Certification & External Assurance Readiness

XPeX distinguishes **internal controls**, **independent verification**, **formal audits** and **certification**.

## Current position

XAGF is an internal governance framework.

It is informed by recognized external frameworks, but XPeX does not claim ISO, SOC 2, NIST, OWASP or SLSA certification merely because related controls are implemented.

## External-assurance path

### Stage A — Internal control system
- policies;
- owners;
- control catalog;
- evidence;
- automated validation;
- risk register;
- incident process;
- system/agent passports.

### Stage B — Independent technical assurance
- penetration test;
- AI red-team;
- supply-chain review;
- access-control review;
- backup/recovery exercise;
- independent evidence verification.

### Stage C — Audit readiness
Potential programs, depending on customers and jurisdiction:
- SOC 2 readiness/audit;
- ISO/IEC 27001 readiness/certification;
- ISO/IEC 42001 readiness/certification;
- privacy/legal reviews;
- customer-specific security assessments.

### Stage D — Continuous assurance
- continuous control monitoring;
- automated evidence collection;
- exception expiry;
- deployment attestations;
- agent runtime telemetry;
- periodic independent reviews.

## Rule

Never display a certification badge before the certification is formally earned and current.
