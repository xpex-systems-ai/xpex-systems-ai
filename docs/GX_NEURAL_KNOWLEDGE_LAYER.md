# GX Neural Knowledge Layer — V2

## Mission

GX becomes the AI interface to the XPeX ecosystem by consuming a governed knowledge layer, not by copying private chat memory into a public model.

The core object is `data/company/neural-system-catalog-v2.json`.

Each canonical system record contains:
- identity and role;
- portfolio tier;
- current evidence-gated state;
- description;
- technology stack;
- runtime/provider truth;
- evidence links;
- visual-asset classification;
- open admission/hardening gates.

## Neural transfer model

```text
AUDIT / PROVIDER / SOURCE EVIDENCE
        ↓
CANONICAL SYSTEM IDENTITY
        ↓
NEURAL SYSTEM CATALOG
        ├──→ SYSTEM INTELLIGENCE PAGES
        ├──→ GX RETRIEVAL CONTEXT
        ├──→ TRUST / EVIDENCE LINKS
        └──→ FUTURE PRIVATE COPILOT TOOLS
```

This is the safe form of "neural transfer": transfer structured, provenance-aware company knowledge into GX while preserving security and truth boundaries.

## Netflix-style system pages

The corporate site exposes a horizontal catalog. Every system opens a dedicated intelligence view containing runtime truth, stack, evidence graph, media state, open gates and its raw machine-readable JSON.

The first V2 registry covers all 10 portfolio systems. The seven flagships have richer evidence; the remaining three are explicitly marked evidence-limited rather than being inflated into flagship claims.

## Next private-copilot layer

The next architecture layer should remain authenticated and separate from the public concierge:

```text
GX PRIVATE COPILOT
  → authenticated operator identity
  → scoped connectors/tools
  → Systems Command registry
  → evidence retrieval
  → policy engine
  → approval boundary
  → action adapters
  → immutable action/evidence log
```

No private tool is granted merely because GX can describe a system.

Knowledge permission and action permission are separate.
