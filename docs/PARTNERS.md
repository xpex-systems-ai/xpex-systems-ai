# Technology & Partnership Policy

XPeX Systems AI is designed to integrate with leading AI, cloud, data and developer ecosystems.

## Important distinction

**Technology usage is not the same as a formal partnership.**

We track relationship maturity explicitly:

```text
TECHNOLOGY_USED
  ↓
INTEGRATION_AVAILABLE
  ↓
MARKETPLACE_LISTED
  ↓
PROGRAM_MEMBER
  ↓
FORMAL_PARTNER
  ↓
COSELL_PARTNER
```

## Current public posture

The public provider registry distinguishes:
- technologies already used in audited systems;
- integration targets;
- future partner/program targets.

No provider should be represented as a formal partner unless evidence exists.

## Strategic partner categories

XPeX intends to build relationships across:

### AI / Models
Model and agent providers, model ecosystems, routing layers and inference providers.

### Cloud / Runtime
Deployment, compute, serverless, observability and infrastructure platforms.

### Data
Databases, vector search, data platforms, storage and analytics.

### Developer Ecosystem
Source control, CI/CD, plugins, MCP/connectors, APIs and developer tooling.

### Enterprise / Channels
Consultancies, education institutions, SaaS ecosystems and enterprise implementation partners.

## Partner-ready assets

XPeX is building:
- XAGF governance framework;
- public Trust Center;
- provider registry;
- evidence-backed product catalog;
- enterprise architecture;
- controlled demo environment;
- investor/partner data room.

## Commercial principle

Partnership announcements must describe the relationship accurately.

Examples:

Allowed:
- "Built with Vercel"
- "Uses Railway infrastructure"
- "Integrates with OpenAI APIs"

Only with formal evidence:
- "Official partner"
- "Strategic partner"
- "Co-selling partner"
