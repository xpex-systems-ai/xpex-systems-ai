# OMNIX Configuration Integrity Audit — minuta comercial

**DRAFT — aprovação do fundador pendente.** Não é oferta contratada, contrato assinado, preço público definitivo ou receita. Não receber arquivos reais até aprovação do fluxo de armazenamento, identidade, privacidade, revisão e entrega.

## Oferta delimitada

Um `vercel.json` sanitizado e autorizado, até 16.000 caracteres, submetido aos checks existentes `vercel_api_routing` e `vercel_security_headers`. Entrega: escopo registrado, achados com evidências, recomendação delimitada, revisão humana independente e relatório JSON com referências e hash. Nenhuma URL é buscada pelo motor.

O primeiro check detecta o padrão específico de fallback SPA que pode interceptar API sem rewrite anterior reconhecido. O segundo examina declarações globais de CSP e X-Content-Type-Options. Presença de declaração não comprova headers entregues nem qualidade completa da CSP.

Exclusões: pentest, varredura de rede/site, acessos administrativos, alteração/deploy de configurações, auditoria universal, certificação, análise jurídica, garantia de segurança/receita, conteúdo de redes sociais/lojas/contas de parceiros. O relatório não confirma disponibilidade real de API sem verificação separadamente autorizada.

Hipóteses para aprovação: **R$490 por arquivo/rodada**, prazo de **3 dias úteis** após escopo, canal seguro, autorização, revisor e condições de pagamento aprovados. Uma rodada de esclarecimentos de achados; novo arquivo/escopo exige nova proposta. São decisões internas candidatas, sem pesquisa de preço ou SLA validado. Tributos/documento fiscal, pagamento, cancelamento, responsabilidade e proteção de dados precisam constar da proposta final aprovada. Nenhuma cobrança automática/Stripe.

Aceite técnico proposto: os dois checks terminam com estado explícito; achados apontam para evidências existentes; identidade do revisor difere do operador; caso fechado exporta JSON verificável; limitações são declaradas. Falha de infraestrutura não vira resultado aprovado. Correções no sistema do comprador ficam fora desta entrega.
