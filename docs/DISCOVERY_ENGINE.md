# XPeX Founder Discovery Engine — V1

## Goal

Make Junior Sena discoverable by the right technical audience and make every discovery path verifiable.

The objective is not mass visibility.

The objective is **qualified technical discovery** by:
- Applied AI / agent engineering teams;
- technical recruiters;
- founders;
- accelerator partners;
- engineering leaders;
- enterprise AI buyers;
- technical investors.

## Discovery architecture

```text
LINKEDIN
  ↓
FOUNDER IDENTITY
  ↓
XPeX SYSTEMS AI
  ↓
CORPORATE SITE
  ↓
FLAGSHIP CASE
  ↓
LIVE SYSTEM
  ↓
SOURCE / DEPLOYMENT / TRUST
  ↓
CONVERSATION
```

## Channels

### LinkedIn — discovery
Use:
- recruiter search;
- short technical posts;
- architecture screenshots;
- launch notes;
- engineering lessons;
- flagship demos.

Do not use:
- vague motivational claims;
- unverified valuation claims;
- unsupported security equivalence;
- daily product-name churn.

### GitHub — technical proof
Use:
- pinned flagship repositories;
- corporate repository;
- clean READMEs;
- issue/PR history;
- security and assurance checks.

### XPeX corporate site — narrative
Use:
- canonical company positioning;
- 5–7 flagships;
- founder identity;
- Trust Layer;
- case links;
- direct technical review paths.

### Demos — conversion
Use 60–180 second clips.

Every clip should answer:
1. What problem is this?
2. What did we build?
3. What is running?
4. What is the difficult engineering decision?
5. Where is the evidence?

## Posting standard

Each technical post should contain:
- one specific engineering insight;
- one concrete system;
- one screenshot or architecture view when possible;
- one verifiable link;
- no more than one CTA.

## Recruiter conversion

A recruiter should be able to answer these questions in under five minutes:

- Who is Junior Sena?
- What role does he actually perform?
- What has he built?
- Is anything deployed?
- Can I inspect the work?
- Does he understand limitations and security?
- Which role family should I evaluate him for?

If those answers require a private explanation from the founder, the discovery system is incomplete.
