# XPeX Systems AI — Product Portfolio

XPeX separates **product family**, **system**, **deployment** and **commercial status**.

A product can exist before it is production-ready. A deployment can be live without being an approved flagship.

## Flagship admission

A public flagship must pass:
1. canonical identity;
2. source position known;
3. ownership/license known;
4. runtime verified;
5. security review;
6. public description approved;
7. public evidence record;
8. truthful commercial status.

## Status vocabulary

- **DISCOVERED** — observed in an authorized source
- **CLASSIFIED** — purpose/type classified
- **CORROBORATED** — supported by more than one evidence source
- **CANONICAL_CANDIDATE** — candidate for authoritative product/system
- **CANONICAL** — approved authoritative identity
- **DEPLOYED** — a runtime deployment exists
- **VERIFIED_LIVE** — runtime and required evidence verified
- **COMMERCIAL** — commercial state supported by evidence
- **LEGACY** — retained for historical or dependency reasons
- **ARCHIVED** — intentionally retired

## Principle

**We would rather present five verified systems than fifty unverified projects.**
