# XPeX Systems AI — Data Room Index V1

This index defines the structure of the future investor and strategic-partner data room.

## 01 — Company
- Company manifesto
- Executive summary
- Founder / leadership profile
- Company structure
- Legal entity records when available

## 02 — Product
- Product map
- Flagship portfolio
- Architecture
- Product roadmap
- Live-demo index
- Canonical repository index

## 03 — Technology
- Systems Command architecture
- GXEON architecture
- NEXARA target architecture
- Infrastructure map
- Data architecture
- Security architecture
- AI-provider strategy

## 04 — Evidence
- Source audits
- Deployment audits
- Ownership evidence
- Runtime verification
- Security reviews
- Evidence coverage reports

## 05 — Commercial
- Customer pipeline
- Proposals
- Contracts
- Paid revenue evidence
- Pricing
- Unit economics
- Sales motion

## 06 — Financial
- Historical actuals
- Budget
- Forecast
- Cash position
- Funding plan
- Use of funds

Financial claims must distinguish planned, contracted, invoiced and paid amounts.

## 07 — Legal / IP
- Trademark status
- Open-source attribution
- Fork lineage
- Licensing
- Customer agreements
- Partnership agreements

## 08 — Security
- Secret-management policy
- Access-control policy
- Incident-response plan
- Backup/recovery
- Supply-chain controls
- Vulnerability register

## 09 — Fundraising
- Investor deck
- Market thesis
- Financing target
- Milestones
- Use of funds
- Risk register

## Access policy

The data room is private by default. Documents are promoted only when their source is known, sensitive data is controlled, metrics are verified, and legal/financial claims are correctly qualified.
