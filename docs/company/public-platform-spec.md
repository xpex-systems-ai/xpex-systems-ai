# XPeX Systems AI — Public Platform V1

## Design language

Primary brand: XPeX Systems AI  
Visual language: black / gold / white, premium enterprise, cinematic but data-led  
Tone: confident, technical, evidence-based  
Avoid: inflated futuristic claims without proof

## Home

Hero:
- XPeX Systems AI
- AI Systems, Agents & Company Intelligence
- Build. Connect. Operate. Prove.

Primary calls to action:
- Explore Verified Systems
- View Company Graph
- Request Enterprise Demo

## Public modules

### 1. Verified Systems
Public list of systems with approved status.

Fields:
- name
- category
- role
- public status
- verified source
- verified deployment
- public demo
- evidence summary
- last verification date

### 2. Products
Commercial product catalog.

### 3. Agents
Approved agent capabilities, without private prompts or credentials.

### 4. Company Graph
Sanitized graph of products, systems and infrastructure.

### 5. Technology
Providers and technologies used.
Provider logos should be described as technologies used unless formal partnership evidence exists.

### 6. Evidence
Explain the Evidence First methodology and show sanitized proof summaries.

### 7. Cases
Real case studies only.

### 8. Company
Vision, manifesto, leadership and contact.

### 9. Investor / Partner Room
Initially private or controlled-access.

Contents:
- company thesis
- product map
- traction
- verified metrics
- market thesis
- roadmap
- use of funds
- risks
- data room index

## Public metric rule

Every number displayed on the homepage must resolve to:
`metric → registry query → source evidence → verification date`

No hard-coded vanity metrics in production.
