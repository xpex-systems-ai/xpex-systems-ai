# XPeX — Private Document Request Index

Public index only. A private data room has not been provisioned by publishing this file. Do not upload completed documents to this public repository or its public website.

| Area | Documents to obtain privately | Review criterion |
| --- | --- | --- |
| Entity | Official registration, jurisdiction, incorporation date, ownership/cap table, representation powers | Authentic current documents and authority confirmed |
| IP | Contributor/contractor assignments, upstream/license register, brand/domain title | Rights, obligations and offered transfer scope identified |
| Commercial | Authorized pipeline, signed contracts, delivery acceptance, customer references | Evidence by state; public use approved by the customer |
| Financial | Bank/provider statements, invoices, settled receipts, expenses, debts, tax/accounting records | Reconciled actuals, currencies and dates; no unknown-to-zero conversion |
| Operations | Provider billing/administration, backup/restore records, access review, incident register | Sensitive data minimized and access controlled |
| Transaction | Owner objective, investment/sale scope, valuation assumptions, transition expectations | Legal and accounting review before commitment |

## Access process to implement

Select a private storage environment administered by the owner, establish named reviewer access and revocation, enable an access record, and agree confidentiality/disclosure terms where required. Admit files only after classification and redaction. Avoid public links for private records.

## Financial input template

Use `templates/company-preparation/financial-inputs.json` as an empty schema/example. Keep completed versions privately. Null means unknown, not zero. Classify each figure as estimated, documented, contracted, invoiced or settled and attach its source/date. The public company package does not contain financial statements or identity documents.

## Founder inputs remaining

The owner must supply or confirm the legal entity, ownership, available operating budget, actual costs/obligations, commercial evidence, desired transaction path and expectations for post-sale participation. These facts cannot be inferred from a website or connected tool account.
