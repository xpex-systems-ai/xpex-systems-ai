## Portfolio admission rule

A product can be called a public flagship only when it meets the required gates:

1. canonical identity assigned;
2. official source-code position known;
3. deployment/runtime verified;
4. security blockers reviewed;
5. public description approved;
6. public evidence record created;
7. no claim exceeds the evidence.

## Initial portfolio target

The Public Portfolio V1 should launch with a small number of high-confidence systems rather than a large catalog.

Target: **4–7 flagship systems**.

Everything else remains discoverable internally as prototypes, components, versions, legacy assets, research or commercial candidates.
