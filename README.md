## Evidence First

We separate vision from proof.

A public claim should be backed by evidence such as source-code lineage, deployment status, runtime verification, ownership evidence, customer evidence or confirmed financial records.

**Prime governance rule:**

> **THE EXECUTOR DOES NOT APPROVE ITS OWN DELIVERY.**

## Product maturity

```text
DISCOVERED → CLASSIFIED → CORROBORATED → CANONICAL_CANDIDATE → CANONICAL → DEPLOYED → VERIFIED_LIVE → COMMERCIAL
```

Not every experiment needs to become a product. The company registry exists to identify which systems deserve to become canonical, secure, live and commercial.
