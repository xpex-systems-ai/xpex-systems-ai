# Support

## Product / documentation questions

Use GitHub Issues for:
- documentation questions;
- reproducible bugs in public artifacts;
- governance-framework questions;
- feature proposals appropriate for public discussion.

## Security

Do **not** post secrets, credentials, customer data or active exploit details in public issues.

Follow `SECURITY.md`.

When GitHub Private Vulnerability Reporting or Security Advisories are enabled, use the private channel for security-sensitive reports.

## Enterprise / partnership

The public corporate platform will provide a controlled enterprise/contact flow.

Until that launch, this repository is the technical source of truth for public company architecture, governance and product status.
